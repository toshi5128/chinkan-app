# 賃管特訓

賃貸不動産経営管理士試験（令和8年11月15日）に向けた個人用の学習アプリ。

- 一問一答（○×・534問）＋忘却曲線にそった復習（1→3→7→14→30日）
- 試験日から逆算した「今日の分」
- ○×の文を組み合わせて本番形式（4択50問・120分、個数・組合せ問題あり）の模試を自動生成
- 記録は端末の localStorage。記録タブからバックアップ（コピー／戻す）

問題は `data/A〜E.json`（分野別400問）と `data/X1〜X4.json`（教科書の手薄なSectionを補う134問）。すべてオリジナル作成で、過去問の転載ではありません。
各問の `sec` は「みんなが欲しかった！賃貸不動産経営管理士の教科書」のSection番号（`sections.json` に目次とページ）。既存問題への付与は `tools_map_sections.py`。

- 教科書タブ：Sectionごとに「読んだ」チェックと、そのSectionだけを解く。10/25までに1周する日割り（遅れたら自動で組み直し）
